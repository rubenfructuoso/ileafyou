- Fehler gefunden: Synchronisierte ein Gerät mit älterem Stand, gewann dessen alte Fassung einer Pflanze, und der Server löschte dabei Fotos, die das andere Gerät noch brauchte. So verschwanden Fotos und «später giessen» sprang zurück.
- Jetzt gewinnt bei Konflikten immer die neuere Änderung (pro Pflanze und pro Protokoll-Eintrag), der Server löscht keine Fotos mehr, und fehlt ein Foto auf dem Server, bleibt das auf dem Gerät erhalten.
- Mit zwei simulierten Geräten getestet: Der alte Code verlor das Foto, der neue behält Foto und Verschiebung.
- Offen: Bereits gelöschte Fotos lassen sich nur aus einem Datenbank-Backup von Hosttech zurückholen.
